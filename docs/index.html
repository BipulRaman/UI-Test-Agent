Quick start

Safety

Read-only by design

The agent's editFiles capability is whitelisted to test and report folders only — it can scaffold and write reports, but never modifies the product it tests. Same-origin crawls are capped at 25 pages by default. Real credentials and destructive actions are refused unless explicitly authorized.

  • No writes outside ./.ui-tests/ and its reports/ subfolder
  • Crawl depth and page count capped by default
  • Refuses destructive actions (deletes, payments, account changes) without explicit consent
  • Locally edited prompt files are preserved across extension upgrades
FAQ

Frequently asked

Do I need a GitHub Copilot subscription?

Yes. The agent runs on top of GitHub Copilot Chat in Agent Mode, so an active GitHub Copilot subscription (Individual, Business, Enterprise, or Free trial) with Copilot Chat enabled and signed in is required. Without it, Copilot Chat is unavailable and the agent cannot run.

Do I need to write any test code?

No. You write Markdown — or just a sentence in chat. The agent interprets it, runs the checks, and writes the report.

Where do reports get written?

By default into ./.ui-tests/reports/ in your workspace. Each run produces a per-case Markdown file plus a roll-up summary.

Can it run in CI?

Today the agent is interactive (Copilot Chat). The scaffolded .ui-test.md files are designed to be portable so you can plug them into a future headless runner.

Will it modify my source code?

No. Its editFiles capability is whitelisted to ./.ui-tests/ only. Application source is strictly read-only.

Does it support custom Chrome paths or channels?

Yes — uiTestAgent.chromeExecutablePath and uiTestAgent.chromeChannel let you point at a specific Chrome / Chromium / Edge binary.

What happens to my prompt files when the extension updates?

Files you've edited locally are preserved untouched. Only files matching the previously installed version are updated. You can force-overwrite with the Install / Update Prompt Files command.
